# ADR-0002: ライセンスと第三者著作物の扱い

- **ステータス:** 採択
- **日付:** 2026-08-08

## 背景

公開リポジトリとして GitHub に置く。ライセンスを決める必要がある。

制約条件:

- 本プロジェクトは `kindle_shot`（MIT）のテキスト処理層を派生元として利用する（[ADR-0001](0001-architecture.md)）
- OCR エンジンとして NDLOCR-Lite（CC BY 4.0, 国立国会図書館）を利用する
- 購入済み書籍の私的複製を支援するツールであり、サービス利用規約との関係でグレーな領域にある
- Rust と Python の混成プロジェクトである

## 決定

### ライセンス: MIT OR Apache-2.0（デュアル）

利用者がいずれかを選択できる。Rust エコシステムの慣習に従う。

- `LICENSE-APACHE` — Apache License, Version 2.0（原典 <https://www.apache.org/licenses/LICENSE-2.0.txt> より取得）
- `LICENSE-MIT` — MIT License, Copyright (c) 2026 numachang
- Cargo の `license` フィールドは `"MIT OR Apache-2.0"`

### 選定理由

**デュアルにする理由:**

- Rust プロジェクトの事実上の標準であり、コントリビューターが驚かない
- ワークスペース内の crate（`ke-imaging` など）を将来 crates.io に公開する余地を残せる
- MIT 側があることで、派生元の `kindle_shot`（MIT）と摩擦なく整合する

**Apache-2.0 を含める理由:**

- **免責条項が強い。** MIT の免責は末尾 1 文だが、Apache-2.0 は §7（無保証）と §8（責任制限）で
  明示的かつ詳細。利用規約との関係がグレーな領域のツールでは、これが実利になる
- **§5 によりコントリビューションが自動的に同ライセンス扱いになる。** CLA を用意せずに済む
- **§3 の特許許諾**が無償で付き、コントリビューターによる後発の特許主張リスクを閉じられる

**採用しなかった選択肢:**

| | 却下理由 |
|---|---|
| MIT 単独 | 実用上は十分だが、免責が 1 文のみ・特許条項なし。デュアルにすれば両方の利点が得られる |
| Apache-2.0 単独 | GPLv2 プロジェクトから利用できなくなる。デュアルにしない理由がない |
| GPL-3.0 / AGPL-3.0 | Python 側まで波及して取り回しが悪い。また上流の `kindle_shot` が MIT で提供しているものを一方通行の copyleft に変えるのは筋が良くない |

> 法人等の名義で公表するもの」を対象とする。本プロジェクトは私用時間・私用機材による

### 第三者著作物

詳細は [THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md) に記録する。要点のみ:

**kindle_shot（MIT）**

Apache-2.0 のプロジェクトに MIT コードを取り込むことは合法である（MIT が sublicense を
許諾しているため）。ただし元の著作権表示を保持する義務があるため、派生ファイルの冒頭に
由来を明記し、THIRD-PARTY-NOTICES.md に MIT 全文を掲載する。

**未解決の問題:** 配布された ZIP に `LICENSE` ファイルが存在せず、著作権者の氏名が不明。
MIT である旨は `pyproject.toml` の 1 行と note 記事本文の記載のみを根拠とする。
つまり MIT が要求する「保持すべき著作権表示」が原配布物に存在しない。
暫定的にハンドル名（lytton）と配布元 URL で帰属表示を行い、著作者に確認を試みる。

**NDLOCR-Lite（CC BY 4.0）**

セットアップ時に取得する構成とし、本リポジトリには同梱しない。README と
THIRD-PARTY-NOTICES.md に帰属表示を記載する。
**ONNX モデルファイルを同梱する構成に変更する場合は、CC BY 4.0 の帰属表示義務が
配布物にも及ぶ**ため、その時点で本 ADR を更新する。

**推移的依存**

実装着手後に `cargo about` および `pip-licenses` で自動生成した一覧を
THIRD-PARTY-NOTICES.md に追記し、CI でその生成物が最新であることを検証する。

### ライセンス以外で必要な措置

ライセンスは利用者の行為に法的な正当性を与えるものではない。以下を README に明記する。

- 利用者自身が購入した書籍の私的複製（著作権法 30 条）を支援する目的であること
- 画面に表示された内容を取得する方式であり、DRM の技術的保護手段を回避する機能は含まないこと
- 各サービスの利用規約に抵触する可能性があり、利用は各自の責任と判断によること
- 出力物の再配布・共有・公開を行わないこと
- Kindle / Amazon は Amazon.com, Inc. またはその関連会社の商標であり、本プロジェクトは
  Amazon と無関係であること（プロジェクト名における商標への言及は指示的使用）

## 影響

- ヘッダに SPDX 識別子 `SPDX-License-Identifier: MIT OR Apache-2.0` を付与できる
- 派生ファイルには追加で由来コメントが必要になる（機械的にはチェックできないため、
  レビュー時の確認事項とする）
- 著作者への確認が取れ次第、THIRD-PARTY-NOTICES.md の帰属表示を更新する
